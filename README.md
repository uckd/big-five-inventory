# big-five-inventory

日本語版 Big Five Inventory-2（BFI-2-J）の60項目に回答し、5ドメインと15ファセットの得点をブラウザ内で計算・表示する静的Webツールです。

## 特徴

- 1〜5の5件法で60項目に回答
- 逆転項目を自動処理
- 5ドメイン（各12項目）と15ファセット（各4項目）の平均得点を表示
- 回答データはブラウザ外へ送信・保存しない
- 外部ライブラリ・ビルド処理なし
- GitHub Pagesなどの静的ホスティングで配信可能
- Node.js標準テストランナーによる採点ロジックのテスト付き

## 得点化

逆転項目は `6 - 回答値` で変換したうえで、以下の平均を計算します。

- ドメイン得点 = 該当する12項目の得点合計 / 12
- ファセット得点 = 該当する4項目の得点合計 / 4

結果は1〜5の範囲で表示されます。パーセンタイルや診断カテゴリへの変換は行いません。

## ローカルで開く

ES Modulesを使用しているため、ローカルファイルを直接開くのではなくHTTPサーバー経由でアクセスしてください。

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000` をブラウザで開きます。

## テスト

Node.js 18以降を想定しています。

```bash
npm test
```
